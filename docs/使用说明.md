# ShotBridge 摄像机运镜描述器 v1.0.0　使用说明

把 Maya 里摄像机的运动，一键变成可以直接粘贴给 AI 视频生成平台的中文运镜提示词。

---

## 一、这是什么

在 Maya 里选好摄像机和被摄主体、设好播放范围，点一下"自动描述运镜"，工具会：

1. 按整数帧逐帧读取摄像机的世界位置、朝向和镜头参数；
2. 转换成摄像机局部坐标，判断推进/拉远、横移、升降、横摇、俯仰、滚转、变焦；
3. 合并成若干个时间段，写出中文运镜提示词（直接可用），同时给一份结构化的 JSON 详情（给后续工具用）。

输出示例：

- "第 0–42 帧：镜头缓慢向前推进约 3.2 个单位，同时持续朝向主体……"
- "第 42–96 帧：镜头向左横摇约 24 度，速度先快后慢……"

---

## 二、系统要求

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（用系统自带 PowerShell 5.1 即可） |
| Maya | Maya 2026（本包在此版本上实测）；Maya 2024 / 2025 理论上可用，但未实机验证 |
| 权限 | 安装到当前用户目录，不需要管理员权限 |

---

## 三、安装（双击即可）

1. 把整个 `ShotBridge_CameraDescriber_v1.0.0` 文件夹放在任意位置（不要放在 Maya 安装目录里）。
2. 双击 **① 一键安装到Maya.bat**。
3. 看到"安装成功"后按任意键关闭窗口。如果此时 Maya 正开着，脚本会提示你重启 Maya。

### 安装到底做了什么（全部可逆）

| 动作 | 位置 |
| --- | --- |
| 复制插件代码 | `C:\Users\<你>\Documents\maya\ShotBridge` |
| 写 Maya 模块声明（让 Maya 启动时加载插件） | `C:\Users\<你>\Documents\maya\modules\ShotBridge.mod` |
| 备份旧版本 | `C:\Users\<你>\Documents\maya\ShotBridge_backup`（含旧 .mod 和旧插件目录） |

**不会**修改 Maya 安装目录，**不会**改你自己的 `userSetup.py`，**不会**动你现有的场景文件。
"启动时自动挂工具架按钮"是通过插件模块自带的 `scripts/userSetup.py` 实现的，属于 Maya 模块的标准机制。

---

## 四、打开工具

**方式 A（推荐）**：双击 **② 启动Maya并打开工具.bat** —— 启动 Maya，并自动把运镜描述器窗口弹出来。

**方式 B**：自己打开 Maya，在顶部工具架找到 **ShotBridge** 页签，点 **运镜描述** 按钮。

> 若 Maya 已经开着，方式 A 不会重复启动 Maya，而是提示你去点工具架按钮（Maya 的模块只会在启动时加载）。
>
> 自动化验收里发现：个别机器上 Maya 启动流程可能打断首次弹窗。本版已内置兜底——启动完成后 3 秒窗口仍不存在时会自动再打开一次；即使仍没出现，也可以直接从工具架 ShotBridge 页签点"运镜描述"。

---

## 五、三步出提示词

1. **获取摄像机**：在 Maya 里选中摄像机，点"获取所选摄像机"。
2. **（可选）添加主体**：选中被摄物体（可多选），点"添加所选目标"。有主体时提示词会包含距离、环绕、构图等信息。
3. **设好播放范围** → 点 **"自动描述运镜"** → 在"中文提示词"页签里点 **"复制提示词"**。

### 界面速查

| 区域 | 说明 |
| --- | --- |
| 分析范围 | 读取 Maya 时间滑块（播放范围），逐帧采样；在 Maya 里改了范围就点"刷新范围" |
| 被摄主体 | 可添加多个，多个主体取中心平均值、包围盒取整体 |
| 高级设置 → 异常判定容差 | 数值越大越宽容；只影响"突然跳一下又回来"的单帧异常被过滤的程度 |
| 高级设置 → 分段合并强度 | 即时生效：数值越高段落越少、越精炼；不会重新读场景 |
| 结构化详情 | 完整的 JSON（通道值、每段度量、主体关系、警告），给后续工具或自己排查用 |
| ？按钮 | 内置完整帮助（快速开始 / 计算内容 / 容差与限制） |

## 六、示例场景

`app\examples\SB_CameraMotion_Validation.ma` 是一个验证场景：一台带 120 帧动画的摄像机 + 若干被摄物体。
可以在 Maya 里直接打开它练手（打开后选摄像机、再点"获取所选摄像机"即可）。

## 七、自检（可选）

双击 **④ 自检.bat**：会用 Maya 自带的 mayapy 跑一遍单元测试和集成测试，最后打印"自检通过"。
适合在怀疑装坏了、或换电脑重装后确认。

---

## 八、卸载

双击 **③ 卸载.bat**，输入 `y` 确认。默认行为：

- 删除 `Documents\maya\ShotBridge` 和 `Documents\maya\modules\ShotBridge.mod`
- 如果安装前有旧版本，自动从备份恢复旧 .mod
- 备份目录 `ShotBridge_backup` 会保留（想彻底清掉手动删即可）
- 工具架上的 ShotBridge 页签默认保留（想一起删，用 `-RemoveShelf` 参数运行 uninstall.ps1）

---

## 九、已知限制

- 只按整数帧采样，不做子帧分析。
- 构图判断是透视近似，不判断遮挡、镜头畸变、画面边缘是否精确相交。
- 提示词偏"检测记录"风格，复杂运动会拆成较多时间段，个别极端情况可能出现零长度的区间提示；以人工复检为准。
- 分析进行中窗口会禁止关闭（约几秒，视帧数而定），这是为了防止关闭窗口时后台回调访问已释放的控件。
- 一个 Maya 会话里窗口是单例：再次打开会复用当前窗口。

## 十、常见问题

**Q：工具架里没有 ShotBridge 页签？**
Maya 完全退出再重开；或菜单 Windows → General → Shelf 里看页签列表。若仍没有，双击 ④ 自检.bat 看输出。

**Q：双击 ② 没反应？**
先把 Maya 全部关掉（包括后台 maya.exe），再双击。

**Q：双击 ② 后 Maya 开了，但工具窗口没自动弹出？**
先看 Maya 顶部工具架有没有 **ShotBridge** 页签：有就点 **运镜描述** 按钮，一样能用。也可以等 3 秒（本版会自动重试一次弹窗）。如果工具架页签也没有，说明模块没被 Maya 加载：完全退出 Maya 再双击 ②，或双击 ④ 自检.bat 看输出。

**Q：中文乱码？**
本包 bat/ps1 已统一 UTF-8，正常在 Windows 10/11 自带 PowerShell 5.1 下运行即可。若你改过系统区域设置导致乱码，不影响功能。

**Q：之前装过开发版（ShotBridge 开发符号链接），会冲突吗？**
安装器会先停用/备份同名 `ShotBridge.mod`，开发版链接会变成备份；想切回开发版，从备份目录把旧 .mod 拿回来即可。

**Q：Maya 版本不是 2026？**
安装器会自动从注册表探测你装的 Maya 版本并写入对应版本号；若是 Maya 2025，请先手动确认再使用（未实机验证）。
